Data Transparency

Privacy Policy

Effective Date: October 1, 2026 | Application Version 1.0.0

1. Architecture and Data Retention

Personal Finance Advisor Bot is developed as an on-premises, self-hosted web application. All personal records, financial transaction entries, budget limits, and savings goals are stored locally in an SQLite database file residing on the host environment where the application is deployed.

We do not operate centralized cloud servers that harvest, aggregate, or distribute your personal financial information. Your transactional data remains under your direct administrative control.

2. Information Handled by the Application

The application stores only the attributes you explicitly submit through the interface:

  • Account credentials: Name, email address, and cryptographically salted password hashes (PBKDF2-SHA256). Plaintext passwords are never persisted.
  • Cash flow records: Income source titles, monetary values in Indian Rupees (₹), dates, and descriptive notes.
  • Expense logs: Category classifications, transaction values, dates, and optional user notes.
  • Planning metrics: Monthly category budgets and target deadlines for designated savings goals.

3. Google Gemini AI Processing

When you explicitly trigger the "Analyze with Gemini AI" feature, the application compiles an aggregated monthly summary (total income, total expenses, category percentages, budget limits, and goal progress) and transmits this payload to the Google Gemini API endpoint using the API key you configure in your local environment file (.env).

Important parameters governing AI processing:

  • Transmission occurs solely upon manual request from the authenticated dashboard.
  • No personal banking credentials, credit card numbers, PAN identifiers, or account numbers are collected or transmitted.
  • Your Gemini API key is loaded strictly on the server-side via environment variables and is never exposed to browser clients or public code repositories.

4. Cookies and Session Management

The application uses a single encrypted session cookie strictly for user authentication. This cookie is configured with HttpOnly and SameSite=Lax flags to protect against cross-site scripting (XSS) and cross-site request forgery (CSRF) vectors. We do not use third-party advertising cookies or cross-site tracking trackers.

5. Data Deletion and Portability

Because the application runs on a local SQLite database, you retain full operational autonomy over your records. You may delete individual records via the user interface, reset demo accounts using the provided seed script, or delete the instance/finance.db database file at any time to purge all stored data permanently.

6. Inquiries and Technical Support

If you have technical questions regarding the data handling mechanisms of Personal Finance Advisor Bot, inspect the open source code repository or review the configuration instructions in the README documentation.
